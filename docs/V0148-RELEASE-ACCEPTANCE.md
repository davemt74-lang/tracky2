# Tracky2 V0.14.8 — ROOM Audio Intelligence Release Acceptance

V0.14.8 closes the ROOM audio intelligence sequence through Section 14.8J. Software readiness requires green deterministic repository checks; live microphone/device certification remains representative-device evidence and is not a universal hardware claim.

## Software gates

- Environmental classification and persistent start/continue/stop activity.
- Speech-origin separation so likely recorded speech stays out of participant Conversation.
- Local music recognition workflow, lyric/transcription fallback, and governed web resolution.
- Recorded TV/movie/streaming/radio/podcast identification.
- Important-sound governance and conservative proactive escalation.
- Owner-labeled personalized local sound learning.
- Owner-grounded audio/visual media fusion.
- ACRCloud exact song recognition with separate owner opt-in.
- Unified ROOM audio orchestration across media types with bounded session continuity.
- Reset/disable/restart behavior that aborts transient remote work and does not persist raw PCM.
- PWA/package/version/audit/CI integrity.

## Privacy and authority

Raw room audio remains transient processing input. The ROOM feed and release evidence contain bounded metadata only. Working lyric/dialogue clues are not participant Conversation turns and are not persisted by release certification. Environmental audio cannot assign participant identity. Remote lyric/media lookup and ACRCloud recognition retain their existing explicit owner opt-ins and provider permission/budget/circuit-breaker boundaries.

## Representative live-device certification

The owner should exercise these scenarios on the target browser/device: sustained music with same-track continuation, track change, TV/video dialogue, radio/podcast speech, foreground live speech over background media, important-sound event, ACRCloud enabled/disabled/no-match, provider failure, microphone interruption/recovery, page hide/restore, and application restart. Results are PASS/FAIL/NOT-RUN metadata only; no raw audio is stored in the certification record.

A representative-device PASS applies only to the tested device/browser/environment. It is not universal hardware certification.
